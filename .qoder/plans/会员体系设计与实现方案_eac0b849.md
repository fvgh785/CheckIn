# 会员体系设计与实现方案

## 一、会员功能价值分析

当前小程序功能仅包含"登录+打卡+基础统计"，对用户而言功能单薄、缺乏长期粘性。引入会员制后，免费用户可继续使用基础打卡，付费会员解锁以下 6 项增值功能：

| 功能 | 免费用户 | 付费会员 | 吸引力 |
|------|:---:|:---:|:---:|
| 每日打卡 | 支持 | 支持 | - |
| 基础统计(连续/累计天数) | 支持 | 支持 | - |
| 打卡日历热力图 | - | 支持 | 视觉激励 |
| 周/月趋势报告 | - | 支持 | 数据洞察 |
| 自定义打卡目标 | - | 支持 | 个性化 |
| 成就徽章系统 | - | 支持 | 游戏化激励 |
| 补签卡(月限3张) | - | 支持 | 容错机制 |
| 订阅消息打卡提醒 | - | 支持 | 提升打卡率 |

## 二、数据库设计变更

### 在 `backend/db.py` 的 `init_db()` 中新增 5 张表：

```sql
-- 会员表
CREATE TABLE memberships (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL UNIQUE,
    level VARCHAR(20) DEFAULT 'premium',   -- 会员等级
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    status TINYINT DEFAULT 1,              -- 1=有效 0=过期
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 打卡目标表（会员可自定义）
CREATE TABLE checkin_goals (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL UNIQUE,
    goal_name VARCHAR(50) DEFAULT '每日打卡',
    icon VARCHAR(50) DEFAULT 'star',
    color VARCHAR(20) DEFAULT '#4A90D9',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 成就表
CREATE TABLE achievements (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL,
    achievement_key VARCHAR(50) NOT NULL,  -- streak_7 / streak_30 / total_100 等
    unlocked_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    UNIQUE KEY unique_user_achievement (user_id, achievement_key)
);

-- 补签卡表
CREATE TABLE makeup_cards (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL,
    used_date DATE NOT NULL,               -- 补签到哪天
    used_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    UNIQUE KEY unique_user_makeup_date (user_id, used_date)
);

-- 打卡提醒设置表
CREATE TABLE reminder_settings (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL UNIQUE,
    enabled TINYINT DEFAULT 0,
    remind_time TIME DEFAULT '08:00',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 三、后端接口设计

### 新增路由文件 `backend/routes/membership.py`

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|:---:|
| GET | `/api/membership/status` | 查询会员状态 | Token |
| POST | `/api/admin/membership/activate` | 管理后台开通会员 | Admin Key |
| GET | `/api/membership/achievements` | 获取已解锁成就 | Token |
| POST | `/api/checkin/makeup` | 使用补签卡 | Token |
| GET | `/api/membership/goal` | 获取打卡目标 | Token |
| PUT | `/api/membership/goal` | 更新打卡目标 | Token+会员 |
| GET | `/api/membership/report` | 周/月趋势报告 | Token+会员 |
| GET | `/api/membership/calendar` | 打卡日历热力图数据 | Token+会员 |
| POST | `/api/membership/reminder` | 设置打卡提醒 | Token+会员 |

### 核心逻辑要点

- **会员校验中间件**：新增 `membership_required` 装饰器，检查 `memberships` 表有效期
- **成就检测**：每次打卡后自动调用 `check_achievements()`，检测是否解锁新成就
- **补签卡限制**：每月限 3 张，检查 `makeup_cards` 表中当月已使用数量
- **日历热力图**：返回近 365 天的打卡日期数组，前端渲染
- **趋势报告**：按周/月聚合打卡数据，计算打卡率、趋势变化

### 管理后台简单实现

在 `backend/app.py` 中新增 admin blueprint，通过环境变量 `ADMIN_KEY` 做简单鉴权：
- `POST /api/admin/membership/activate` — 为指定用户激活会员（需传 userId 和月份数）

## 六、技术注意事项

- ECharts 微信版需引入 `ec-canvas` 组件用于图表渲染
- 订阅消息推送需要对接微信 `subscribeMessage` API
- 补签卡每月限制通过时间窗口计算（当前自然月内 used_date 计数）
- 会员到期后数据保留，功能降级为免费，续费后恢复访问
